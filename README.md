# 💣 荷姆茲封鎖戰 · Hormuz Blockade

> 你能擋住第幾波美軍？佈雷、發射反艦飛彈，守住荷姆茲海峽 —— 60 秒一局。

**🎮 [開始遊戲](https://jiapunk.github.io/hormuz-blockade/)**

單檔 HTML 遊戲，零依賴、零後端、離線可玩。手機與電腦皆支援。

---

## 玩法

你是伊朗革命衛隊海軍指揮官。美軍第五艦隊正試圖突破荷姆茲海峽，你有兩種武器：

| 武器 | 操作 | 限制 |
|------|------|------|
| 💣 水雷 | 點擊海面佈雷，艦艇接觸即引爆 | 冷卻制 |
| 🚀 反艦飛彈 | 點擊目標直接打擊，範圍傷害 | 彈藥制，擊沉可補充 |

### 敵艦

| 艦種 | 血量 | 分數 |
|------|------|------|
| 偵察艇 | 1 | 10 |
| 驅逐艦 | 2 | 30 |
| 巡洋艦 | 4 | 80 |
| 航空母艦 | 12 | 500 |
| 🛢️ **民用油輪** | — | **-100**（誤擊重罰、連擊歸零） |

油輪是這遊戲的核心張力：讓它安全通過沒有懲罰，但轟掉它會扣分、斷連擊。三艘以上會解鎖「油輪屠夫」結局。

### 系統

- **連擊倍率** — 連續擊沉最高 20 倍分數
- **戰術升級** — 每滿 100 石油三選一：水雷範圍、冷卻縮減、雙發飛彈、分數倍率、補血等，可無限堆疊
- **三條命** — 每有一艘敵艦通過扣一條

## 三種模式

### 🇮🇷 伊朗防禦（主線）
標準封鎖戰，越守越難。

### 📅 每日挑戰
每天自動輪替一種特殊規則，全世界玩家當天條件相同：

| 挑戰 | 規則 |
|------|------|
| 🛢️ 油輪地獄 | 油輪數量 ×3 |
| ⚡ 航母閃電 | 航母提早出現，擊沉分數加倍 |
| 💨 極速模式 | 美艦速度 ×1.5 |
| 💣 水雷戰爭 | 禁用飛彈，水雷冷卻減半 |
| 🚀 飛彈雨 | 飛彈無限，禁用水雷 |
| ⚔️ 全艦隊 | 只出巡洋艦與航母 |
| 💀 一命封鎖 | 只有 1 條命，分數 ×2 |

### 🇺🇸 美軍突破（反向）
換邊玩 —— 駕駛航母閃避水雷與飛彈，強行通過海峽。獨立的升級路線（複合裝甲、匿蹤塗層、機動性）與排行榜。

## 技術

- 單一 `index.html`，約 65KB，1900 行
- Canvas 2D 手寫渲染，無框架、無建置步驟
- Web Audio API 程式合成音效，不載入任何音檔
- 固定時間步長（fixed timestep）— 60Hz / 120Hz / 144Hz 螢幕速度一致
- `localStorage` 安全包裝，Safari 無痕模式與 WebView 不會崩潰
- 粒子數量硬上限，低階手機不掉幀
- 分頁切到背景自動暫停
- iPhone 瀏海與 home bar 安全區適配

### 本機執行

```bash
git clone https://github.com/jiapunk/hormuz-blockade.git
cd hormuz-blockade
open index.html     # 或直接雙擊
```

沒有 `npm install`，沒有建置。改完 `index.html` 重新整理就看到結果。
