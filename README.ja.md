# 💣 ホルムズ海峡封鎖戦 · Hormuz Blockade

> 米海軍の波を何波防げる？機雷を敷き、対艦ミサイルを撃ち、ホルムズ海峡を守れ —— すぐに遊べる。

**🎮 [ゲームをプレイ](https://jiapunk.github.io/hormuz-blockade/)**

シングルファイルの HTML ゲーム。依存関係ゼロ、バックエンド不要、オフラインで遊べる。スマホと PC の両方に対応。

## 遊び方

あなたはイラン革命衛隊海軍の指揮官。米第5艦隊がホルムズ海峡の突破を試みています。武器は2つ：

| 武器 | 操作 | 制限 |
|------|------|------|
| 💣 機雷 | 海面をクリックして敷設。艦船が接触すると爆発 | クールダウン制 |
| 🚀 対艦ミサイル | 目標をクリックして直接攻撃。範囲ダメージ | 弾薬制、撃沈で補充 |

### 敵艦

| 艦種 | HP | スコア |
|------|----|--------|
| 偵察艇 | 1 | 10 |
| 駆逐艦 | 2 | 30 |
| 巡洋艦 | 4 | 80 |
| 航空母艦 | 12 | 500 |
| 🛢️ **民間油タンカー** | — | **-100**（誤撃は大減点、コンボリセット） |

タンカーはこのゲームの核心的な緊張感の源：安全に通過させてもペナルティはなし、しかし撃てば減点＆コンボ中断。3隻以上撃つと「タンカー屠殺者」エンディングが解禁。

### システム

- **コンボ倍率** — 連続撃沈で最大 20 倍のスコア
- **戦術アップグレード** — 石油が溜まるたびに3択（必要量は毎回上昇）：機雷範囲、クールダウン短縮、ツインミサイル、スコア倍率、回復など、無限にスタック可能
- **ライフ 3** — 敵艦が通過するごとに 1 減り、0 で終了

## 3つのモード

### 🇮🇷 イラン防衛（メイン）
標準的な封鎖戦。守るほど激しくなる。

### 📅 デイリーチャレンジ
特別ルールが毎日自動で切り替わり、世界中のプレイヤーが同じ条件で挑戦：

| チャレンジ | ルール |
|-----------|--------|
| 🛢️ タンカー地獄 | タンカー出現率 ×3 |
| ⚡ 空母ブリッツ | 空母が早めに登場、撃沈スコア 2 倍 |
| 💨 超高速モード | 敵艦の速度 ×1.5 |
| 💣 機雷戦 | ミサイル禁止、機雷のクールダウン半減 |
| 🚀 ミサイルラッシュ | ミサイル無限、機雷禁止 |
| ⚔️ 全面艦隊 | 巡洋艦と空母のみ出現 |
| 💀 一命封鎖 | ライフ 1、スコア ×2 |

### 🇺🇸 米軍突破（リバース）
立場を変えてプレイ —— 空母を操り、機雷とミサイルを避けて海峡を強行突破。独自のアップグレードツリー（複合装甲、ステルス塗装、機動性）とランキング。

## 技術

- 単一の `index.html`、約 70KB
- Canvas 2D を手書きレンダリング、フレームワーク不要、ビルド不要
- Web Audio API で効果音を合成、音声ファイルは一切読み込まない
- 固定タイムステップ（fixed timestep）— 60Hz / 120Hz / 144Hz どの画面でも同一速度
- `localStorage` の安全ラッパー — Safari のプライベートモードや WebView でもクラッシュしない
- パーティクル数のハード上限 — 低スペック端末でもカクつかない
- タブがバックグラウンドに移ると自動一時停止
- iPhone のノッチとホームバーのセーフエリア対応

### ローカルで実行

```bash
git clone https://github.com/jiapunk/hormuz-blockade.git
cd hormuz-blockade
open index.html     # またはダブルクリック
```

`npm install` もビルドも不要。`index.html` を編集してリロードするだけ。
