## 玩法

你是伊朗革命卫队海军指挥官。美军第五舰队正试图突破霍尔木兹海峡，你有两种武器：

| 武器 | 操作 | 限制 |
|------|------|------|
| 💣 水雷 | 点击海面布雷，舰艇接触即引爆 | 冷却制 |
| 🚀 反舰导弹 | 点击目标直接打击，范围伤害 | 弹药制，击沉可补充 |

### 敌舰

| 舰种 | 血量 | 分数 |
|------|------|------|
| 侦察艇 | 1 | 10 |
| 驱逐舰 | 2 | 30 |
| 巡洋舰 | 4 | 80 |
| 航空母舰 | 12 | 500 |
| 🛢️ **民用油轮** | — | **-100**（误击重罚、连击清零） |

油轮是这游戏的核心张力：让它安全通过没有惩罚，但轰掉它会扣分、断连击。击沉三艘以上会解锁「油轮屠夫」结局。

### 系统

- **连击倍率** — 连续击沉最高 20 倍分数
- **战术升级** — 石油每达标即可三选一（门槛递增）：水雷范围、冷却缩减、双发导弹、分数倍率、补血等，可无限叠加
- **三条命** — 每有一艘敌舰通过扣一条，用完即结算

## 三种模式

### 🇮🇷 伊朗防御（主线）
标准封锁战，越守越难。

### 📅 每日挑战
每天自动轮换一种特殊规则，全球玩家当天条件相同：

| 挑战 | 规则 |
|------|------|
| 🛢️ 油轮地狱 | 油轮数量 ×3 |
| ⚡ 航母闪电 | 航母提早出现，击沉分数加倍 |
| 💨 极速模式 | 美舰速度 ×1.5 |
| 💣 水雷战争 | 禁用导弹，水雷冷却减半 |
| 🚀 导弹雨 | 导弹无限，禁用水雷 |
| ⚔️ 全舰队 | 只出巡洋舰与航母 |
| 💀 一命封锁 | 只有 1 条命，分数 ×2 |

### 🇺🇸 美军突破（反向）
换边玩 —— 驾驶航母躲避水雷与导弹，强行通过海峡。独立的升级路线（复合装甲、隐身涂层、机动性）与排行榜。

## 技术

- 单一 `index.html`，约 70KB
- Canvas 2D 手写渲染，无框架、无构建步骤
- Web Audio API 程序合成音效，不加载任何音频文件
- 固定时间步长（fixed timestep）— 60Hz / 120Hz / 144Hz 屏幕速度一致
- `localStorage` 安全封装，Safari 无痕模式与 WebView 不会崩溃
- 粒子数量硬上限，低端手机不掉帧
- 标签页切到后台自动暂停
- 适配 iPhone 灵动岛与 Home Indicator 安全区

### 本地运行

```bash
git clone https://github.com/jiapunk/hormuz-blockade.git
cd hormuz-blockade
open index.html     # 或直接双击
```

没有 `npm install`，没有构建。改完 `index.html` 刷新即可看到结果。
